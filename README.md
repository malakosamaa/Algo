To Run Backend:
1-Open Terminal
2-Type command: "cd Backend"
3-Type command: "python app.py"
4-You Should see "Running on http://127.0.0.1:5000"

To Run Frontend: 
1-Open Terminal
2-Type command: "cd Frontend"
3-Type command: "python -m http.server 5500 "
4-Open "http://127.0.0.1:5500" in your browser.

In Browser:
1-Enter all inputs or choose one of the presets buttons.
2-Click Run Simulation.
3-Outputs should appear on browser.
